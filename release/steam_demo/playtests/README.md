# Steam Demo 真人试玩记录

这里记录“首次接触玩家”的受控试玩结果。自动化自检不能替代这些数据。

## 记录方法

1. 复制 `session-template.json`，命名为 `session-YYYYMMDD-01.json`。
2. 使用匿名编号，不记录姓名、邮箱、Steam 账号或其他个人信息。
3. 测试员原则上不口头解释；若必须提示，将 `needed_verbal_help` 设为 `true` 并记录卡点。
4. 一次试玩建议观察 30–45 分钟，但不要为了满足时长阻止玩家主动退出。
5. 完成记录后运行 `tools\summarize_steam_demo_playtests.cmd`。

汇总器会写入 `summary.json` 和 `release_decision.json`。达到以下最低门槛才会给出 `go`：

- 至少 5 名首次接触玩家；
- 至少 80% 在无口头提示下完成首个地区；
- 任一相同阻断问题影响不超过 40% 的样本；
- 至少 60% 表示愿意继续；
- 至少 80% 能明确感受到三个地区的差异。

这些门槛是本项目的内部发布标准，不是 Steam 官方要求，也不能单独证明内容量足够。自由文本反馈和退出原因仍需人工阅读。
