# 庄家开场语与区域转换叙事实实施计划

日期：2026-07-29

## 1. 内容模型

1. 先扩展内容测试，要求三名庄家具有非空开场语、三个区域具有非空远征进入文案。
2. 扩展 `DealerDefinition`、`AreaDefinition` 和内容校验器。
3. 把已确认文案写入 `.tres`，保持内容目录为单一事实来源。

## 2. 共享叙事卡

1. 先添加场景与绑定合同测试。
2. 创建稳定 `.tscn` 节点：类型、标题、说话者、正文、规则/继承摘要、主按钮、安全退出按钮。
3. 脚本只绑定内容、应用无障碍策略并发出确认/退出信号。
4. 增加背景输入阻断和单次确认测试。

## 3. 远征转换

1. 先扩展远征 UI 合同：
   - 新远征先显示首区卡；
   - 空检查点恢复显示当前区域卡；
   - 非空检查点直接挂载；
   - 跨区先保存再显示卡；
   - 确认后才挂载；
   - 最终完成直接总结。
2. 在 `expedition_run_screen.tscn` 实例化共享叙事卡。
3. 在 `ExpeditionRunScreen` 中实现纯边界编排，不改 `ExpeditionSession` 状态合同。
4. 最终总结绑定固定结语。

## 4. 庄家开场

1. 先扩展 AreaRun 场景和交互合同。
2. 在基础 `area_run_screen.tscn` 实例化共享叙事卡。
3. 首次绑定庄家阶段时显示开场；确认后再触发现有庄家提示。
4. 同实例后续轮次不重复；新实例恢复庄家入口时重新显示。

## 5. 验证

1. 新增真实指针自检：首区确认、跨区确认、安全退出、庄家确认和背景阻断。
2. 新增 1280×720 / 1920×1080 布局自检，并覆盖 125% 界面缩放。
3. 运行专项测试、`tests/run_all.gd`、交接基线输入/布局检查和主场景 `--quit`。
4. 检查退出码和 `SCRIPT ERROR|Failed to load script`。
5. 仅提交代码路径，排除全部暂存文档。
