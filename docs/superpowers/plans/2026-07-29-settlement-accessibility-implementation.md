# 结算演出与无障碍设置实施计划

日期：2026-07-29

## 1. 设置数据与服务

1. 先扩展 `settings_service_test.gd`，覆盖无障碍默认值、合法修改、非法值回退、旧配置补齐和保存恢复。
2. 扩展 `SettingsStore` 字段级读取/写入 `accessibility`。
3. 扩展 `SettingsService` 查询、修改、默认恢复、即时保存和变更信号。
4. 保持现有声音和显示测试通过。

## 2. 结算播放模型

1. 新增纯逻辑播放状态测试，覆盖事件顺序、正常/快速/立即、临时加速、跳过和单次完成。
2. 实现不依赖场景树的 `ResolutionPlayback` 状态对象。
3. 播放对象只消费 `ResolutionReport`，不访问解析器或修改报告。

## 3. 结算面板与提交流程

1. 增加结算面板场景合同测试。
2. 在 `resolution_panel.tscn` 增加正式/预测状态、播放进度、加速和跳过控件。
3. 扩展 `ResolutionPanel`：
   - 预测继续即时完整显示；
   - 正式播放逐项追加；
   - 显示来源、旧值、变化量、新值和状态；
   - 应用降低闪光与关闭扭曲策略；
   - 完成信号只发出一次。
4. `SingleEncounterScreen` 在提交后启动播放，播放完成后再发出 `round_committed`。
5. 播放期间锁定本轮编辑控件。

## 4. 无障碍设置 UI

1. 扩展设置场景合同测试。
2. 在 `settings_layer.tscn` 增加“无障碍”标签页和稳定控件。
3. 连接降低闪光、关闭扭曲、结算速度、界面缩放与恢复默认值。
4. 验证旧声音/显示页、暂停和显示确认流程不回归。

## 5. 真实交互与布局

1. 新增结算播放真实指针自检：提交、2×、立即完成、单次父级通知。
2. 扩展设置真实指针自检：无障碍页、开关、速度、缩放和持久化。
3. 新增或扩展 1280×720 与 1920×1080 布局自检。
4. 保留人工验收口径：节奏可读性、闪光舒适度、缩放后的真实可操作性。

## 6. 阶段门

1. 运行专项测试。
2. 运行 `tests/run_all.gd`。
3. 运行交接基线真实输入/布局检查和主场景 `--quit`。
4. 检查日志中的 `SCRIPT ERROR|Failed to load script`。
5. 仅提交代码路径，排除全部暂存文档。
6. 第 4 阶段提交完成后才开始第 5 阶段设计核对。
