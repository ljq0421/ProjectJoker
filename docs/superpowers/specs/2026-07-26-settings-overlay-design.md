# 《六面赌局》全屏设置覆盖层设计规格

> 项目：Project Joker
>
> 日期：2026-07-26
>
> 引擎：Godot 4.6.1
>
> 目标分支：`master`
>
> 状态：设计已确认，等待书面规格复核

## 1. 背景与决策覆盖

项目现有音效系统已建立 `Master -> SFX -> UI / Gameplay` 总线，但第一阶段明确不包含设置页和持久化音量配置。本规格扩展该系统，并覆盖
`2026-07-26-dream-glass-sfx-design.md` 中“只建立可调音频总线、不新增设置页”以及“音量配置不持久化”的旧范围决定。原规格的音效来源、语义事件、无悬停音和商用追溯要求保持不变。

当前游戏没有主菜单，启动后直接进入主遭遇页。设置入口因此必须存在于各主要玩法页面中，并且打开设置时不能销毁当前场景或丢失对局状态。

## 2. 已确认的产品决策

- 所有主要玩法页面右上角都提供可见的“设置”入口。
- 设置界面是全屏玻璃覆盖层，不切换场景。
- 覆盖层打开时暂停游戏并完全拦截底层输入。
- 覆盖层采用左侧分类、右侧内容的侧栏分页布局。
- 声音页提供总音量、界面音效和玩法音效三组滑杆与独立静音开关。
- 声音设置即时生效并可预听。
- 显示页提供窗口/全屏、窗口分辨率和垂直同步。
- 显示设置只在点击“应用显示设置”后生效。
- 声音与已确认的显示设置全部跨启动保存。
- 显示设置应用后必须在 10 秒内确认，否则恢复应用前状态。
- 不新增背景音乐、环境音、语音、辅助功能、玩法选项或按键重映射。

## 3. 目标

1. 玩家可以在任何主要玩法页面中调整声音和显示设置，而不丢失当前对局。
2. 声音调整具有即时、可理解且不过度重复的听觉反馈。
3. 显示设置采用草稿、应用、确认和超时恢复流程，避免把不可用窗口状态持久化。
4. 所有配置都有统一校验、容错和持久化入口，不让页面脚本直接读写操作系统或配置文件。
5. 设置覆盖层与现有“梦境电子玻璃”主题、音效反馈规则和暂停状态兼容。

## 4. 非目标

- 不增加背景音乐或音乐音量选项。
- 不暴露内部 `SFX` 校准总线。
- 不增加独占全屏、无边框窗口、渲染比例、帧率上限、HDR 或显示器选择。
- 不把全屏分辨率伪装成可选项；普通全屏跟随当前显示器尺寸。
- 不增加语言、控制、辅助功能或玩法难度设置。
- 不修改玩法状态、结算规则、存档模型或教程进度。
- 不创建独立设置场景，不实现离开设置页后恢复整场对局的序列化系统。
- 不为悬停、焦点移动、拖动中的每个刻度或显示确认倒计时播放声音。

## 5. 方案选择

### 5.1 采用：常驻设置服务 + 可复用覆盖层

使用 Autoload `SettingsService` 统一管理默认值、运行时设置、显示草稿、校验、应用和持久化。使用一个可复用的
`SettingsLayer` 场景提供右上角入口与全屏设置界面，并在各主要玩法场景中显式实例化。

该方案让入口范围在场景文件中可见，同时确保配置与操作系统调用只存在一份。非玩法场景、测试场景和未来的特殊场景不会因为全局 UI Autoload 而意外出现设置按钮。

### 5.2 不采用：全局设置 UI Autoload

全局 UI 接入代码更少，但会默认出现在所有场景中，并可能与教程、结算层和独立测试场景发生层级、暂停和输入冲突。

### 5.3 不采用：各页面独立实现

各页面分别实现设置控件会重复布局、信号、验证和保存逻辑，后续很容易产生行为差异。

## 6. 文件与组件边界

```text
project.godot

scripts/settings/settings_service.gd
scripts/settings/settings_store.gd
scripts/settings/display_settings_adapter.gd

tests/settings_service_test.gd
tests/settings_ui_contract_test.gd
tests/settings_input_self_check.gd
tests/settings_layout_self_check.gd
```

### 6.1 `SettingsService`

常驻服务负责：

- 定义和提供设置默认值；
- 启动时加载、逐项校验并应用配置；
- 对外提供当前声音值、当前已确认显示值和显示草稿；
- 立即应用声音设置；
- 应用、确认或恢复显示设置；
- 发出设置变化、显示确认倒计时和错误信号；
- 调用 `SettingsStore` 持久化已确认值；
- 调用 `DisplaySettingsAdapter` 操作窗口和垂直同步。

UI 不直接调用 `AudioServer`、`DisplayServer` 或 `ConfigFile`。

`project.godot` 中保留现有 `SfxService`，并在其后注册 `SettingsService`。设置服务在 Autoload 初始化时读取配置；声音值可立即应用，显示值通过延迟调用在根窗口就绪后应用，避免首帧前操作尚未建立的窗口。

### 6.2 `SettingsStore`

独立负责版本化配置的读取、逐项类型校验和临时文件替换保存。它不依赖场景树、音频总线或窗口 API，便于覆盖损坏配置和保存失败测试。

### 6.3 `DisplaySettingsAdapter`

对 `DisplayServer` 的窗口模式、窗口尺寸、屏幕可用区域和 VSync 调用提供小型封装。正式运行使用真实适配器，自动测试可注入假的适配器，避免把 headless 环境的空窗口返回值误判为真实显示行为。

### 6.4 `SettingsLayer`

场景负责：

- 在覆盖层关闭时显示右上角入口；
- 显示侧栏分页、声音控件、显示控件和错误文字；
- 将输入转换为 `SettingsService` 调用；
- 打开时记录并切换暂停状态；
- 关闭时恢复打开前暂停状态；
- 在显示设置待确认期间显示不可绕过的确认层。

## 7. 接入页面

以下五个主要页面显式实例化同一个 `SettingsLayer`：

1. `scenes/run/single_encounter_screen.tscn`
2. `scenes/run/three_round_run_screen.tscn`
3. `scenes/run/gold_corridor_run_screen.tscn`
4. `scenes/run/iron_abacus_slice_screen.tscn`
5. `scenes/shop/shop_screen.tscn`

覆盖层使用高于页面内容、教程和普通结算面板的 `CanvasLayer` 层级。覆盖层打开后，全屏输入拦截 Control 使用
`MOUSE_FILTER_STOP`，设置节点使用暂停时仍处理的进程模式。

## 8. 布局与视觉

### 8.1 入口

- 页面右上角放置 `96 x 48` 的“设置”文字按钮。
- 使用现有梦境电子玻璃按钮主题和明确的中文文本，不依赖 Unicode 齿轮字形。
- 按钮位于安全区内，不覆盖系统窗口按钮或页面主要标题。

### 8.2 全屏覆盖层

- 全屏半透明暗化遮罩保留当前玩法页面轮廓。
- 主玻璃面板包含顶栏、左侧分类和右侧内容区。
- 顶栏显示“设置 / SETTINGS”和关闭按钮。
- 左侧分类只有“声音”和“显示”。
- 右侧一次显示一个分类，不在当前范围不足时预留空白分类。

### 8.3 声音页

每组声音设置包含名称、`0-100%` 数值、滑杆和静音开关：

- 总音量；
- 界面音效；
- 玩法音效。

页面底部提供“恢复声音默认值”。

### 8.4 显示页

显示页包含：

- 显示模式：窗口、全屏；
- 窗口分辨率：`1280 x 720`、`1600 x 900`、`1920 x 1080`；
- 垂直同步：开、关；
- “恢复显示默认值”；
- “应用显示设置”。

全屏模式下分辨率控件禁用并显示“跟随显示器”。窗口分辨率中超出当前屏幕可用区域的档位禁用。

## 9. 暂停与输入规则

打开覆盖层时：

1. 记录 `SceneTree.paused` 的原值；
2. 显示遮罩并把焦点移到第一个可操作控件；
3. 将场景树设为暂停；
4. 拦截所有指向底层的鼠标、键盘和手柄输入；
5. 播放一次 `panel_open`。

关闭覆盖层时：

1. 如果存在未确认显示变更，先恢复显示快照；
2. 丢弃未应用的显示草稿；
3. 隐藏覆盖层；
4. 恢复打开前的暂停值；
5. 播放一次 `panel_close`。

右上角按钮是唯一打开入口。`Esc` 只在覆盖层打开时关闭，不作为隐藏打开入口。显示确认层存在时，普通关闭动作等同“恢复原设置”，不能绕过恢复流程。

## 10. 声音设置数据流

### 10.1 总线映射

| UI 设置 | Godot 总线 | 默认线性值 | 对应现有默认 dB |
|---|---|---:|---:|
| 总音量 | `Master` | `1.0` | `0 dB` |
| 界面音效 | `UI` | `0.501187` | `-6 dB` |
| 玩法音效 | `Gameplay` | `0.794328` | `-2 dB` |

`SFX` 总线继续保持 `-3 dB`，作为内部统一校准层，不显示在设置页。

### 10.2 应用与预听

```text
拖动滑杆
-> SettingsLayer 发送线性值
-> SettingsService 立即更新目标总线
-> UI 数值立即刷新
-> 拖动结束
-> 保存配置
-> 播放一次对应预听音
```

- 总音量与界面音效预听 `ui_confirm`。
- 玩法音效预听 `die_place`。
- 拖动过程中不按刻度重复播放。
- 静音开关立即应用并保存。
- 服务为每组保存最近一次大于零的线性值；从 `0%` 或静音状态恢复时可以恢复最近一次可听值。
- `0%`、静音和 `linear_to_db()` 的负无穷边界由服务统一处理，UI 不直接计算 dB。

### 10.3 恢复默认

“恢复声音默认值”立即恢复三组默认值、取消三组静音、更新总线、保存并播放一次确认音。

## 11. 显示设置数据流

### 11.1 普通全屏语义

全屏使用 `DisplayServer.WINDOW_MODE_FULLSCREEN`，不使用独占全屏。Godot 普通全屏会匹配当前显示器尺寸，且不会改变显示器视频模式。因此：

- 窗口模式使用所选 16:9 窗口尺寸；
- 全屏模式跟随当前显示器尺寸；
- 切换到全屏时保留最近一次窗口尺寸，以便切回窗口时恢复；
- 全屏时不允许编辑一个实际上不会生效的分辨率值。

依据：[Godot 4.6 `DisplayServer.WindowMode` 官方文档](https://docs.godotengine.org/en/4.6/classes/class_displayserver.html#enum-displayserver-windowmode)。

### 11.2 草稿与应用

打开显示页时，控件从已确认显示值创建草稿。修改控件只改变草稿，不调用 `DisplayServer`，也不写配置。

点击“应用显示设置”后：

1. 保存当前运行时显示快照；
2. 校验显示模式、窗口尺寸和 VSync；
3. 按安全顺序应用窗口模式、尺寸、位置和 VSync；
4. 读回运行时值；
5. 如果读回不一致，立即恢复快照并显示错误；
6. 如果一致，显示 10 秒确认层。

点击“保留更改”后才把草稿提升为已确认值并保存。点击“恢复原设置”、倒计时归零、关闭覆盖层、确认层异常中断或进程在保存前退出时，都恢复快照。因为未确认值不写配置，下次启动仍使用上一次已确认设置。

### 11.3 窗口尺寸

- 仅提供 `1280 x 720`、`1600 x 900`、`1920 x 1080`。
- 根据当前屏幕可用区域禁用放不下的窗口尺寸。
- 如果三个预设尺寸都放不下，分辨率选择和切换到窗口模式的应用动作保持禁用，并显示“当前屏幕不足以容纳最低窗口分辨率”；当前窗口状态不变。
- 切换到窗口模式后把窗口放在当前屏幕可用区域中央。
- 如果已保存窗口尺寸在当前显示器上放不下，启动时使用能放下的最大允许尺寸，但不自动覆盖已保存值；玩家确认新显示设置后才更新配置。

### 11.4 VSync

使用 `DisplayServer.window_set_vsync_mode()` 切换启用或禁用。平台或渲染器可能回退到支持的模式，因此应用后必须读回状态；不一致时显示平台不支持提示并恢复快照。

## 12. 配置格式与持久化

配置路径：

```text
user://settings.cfg
```

配置结构：

```ini
[meta]
schema_version=1

[audio]
master_linear=1.0
master_muted=false
master_last_audible=1.0
ui_linear=0.501187
ui_muted=false
ui_last_audible=0.501187
gameplay_linear=0.794328
gameplay_muted=false
gameplay_last_audible=0.794328

[display]
mode="windowed"
window_width=1280
window_height=720
vsync_enabled=true
```

持久化规则：

- 启动时逐项读取与校验；
- 单项缺失、类型错误或越界只恢复该项；
- 整体无法解析时使用默认值，不立即覆盖损坏文件；
- 玩家下一次明确修改设置时写入完整有效配置；
- 保存先写临时文件，成功后替换正式文件；
- 临时文件写入或替换失败时保留旧配置并显示错误；
- 未确认的显示草稿永远不写入配置。

## 13. UI 音效规则

- 覆盖层实际打开：`panel_open`。
- 覆盖层实际关闭：`panel_close`。
- 分类切换实际发生：`ui_confirm`。
- 恢复默认实际发生：`ui_confirm`。
- 显示设置确认保留：`ui_confirm`。
- 显示应用或保存失败并显示错误：`error`。
- 音量拖动结束：对应单次预听音。
- 悬停、焦点移动、拖动中的连续数值变化和倒计时：静音。

静音 UI 总线时，关闭该总线的确认音允许在状态切换前播放；取消静音时在状态切换后播放。一次输入仍只产生一个最具体的声音。

## 14. 异常与恢复

- 未找到目标音频总线：跳过该项、显示错误并保持其他设置可用。
- 配置文件无法解析：使用默认值，保留原文件直到玩家明确修改。
- 临时配置写入失败：保留旧文件，运行时设置继续有效并显示错误。
- 窗口模式或尺寸读回不一致：恢复应用前快照。
- VSync 不受支持或被平台回退：恢复应用前快照并显示平台限制。
- 显示确认超时或被关闭动作中断：恢复应用前快照。
- 覆盖层重复打开：忽略第二次请求，不重复暂停或播放打开音。
- 覆盖层重复关闭：忽略请求，不重复恢复暂停状态或播放关闭音。
- 场景原本已经暂停：关闭设置后仍保持暂停。
- 设置服务失败不得修改玩法状态、教程进度、随机数或对局结果。

## 16. 完成条件
