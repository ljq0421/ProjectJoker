# 结算演出与无障碍设置设计

日期：2026-07-29  
状态：已确认

## 目标

补齐正式结算演出和无障碍设置，使玩家能够看清已提交结果的逐项来源与数值变化，并能够降低、加速或跳过表现。此阶段不改变解析器、得分、奖励、事件顺序或区域流程。

## 已确认事实

- 预览和正式提交已经共享 `ResolutionReport.events`。
- 当前 `ResolutionPanel` 会立即显示完整事件列表和最终总计。
- 当前成功提交会立即发出 `round_committed`，父页面随即进入摘要。
- 设置服务当前仅持久化声音与显示设置。
- 总规格要求正式结算按事件列表播放、可加速或跳过，并提供降低闪光、关闭屏幕扭曲、动画速度和界面缩放。

## 正式结算合同

1. `SingleEncounterSession.commit()` 仍负责一次性原子提交。
2. UI 只播放该次提交返回的 `ResolutionReport`，不重新解析或修改报告。
3. 提交后，`ResolutionPanel` 从零开始按报告事件顺序逐项呈现。
4. 每项同时显示：
   - 玩家可读来源；
   - 变化前累计值；
   - 本项变化量；
   - 变化后累计值；
   - 是否生效。
5. 可映射到当前场景时，同步突出规则台或桌间槽；无法映射的牌、刻印和庄家事件仍通过文本与符号完整表达。
6. 播放完成后才发出一次 `round_committed(report)`，父页面随后进入摘要。
7. 播放过程中不能再次提交或修改本轮；只允许加速、立即完成和打开共享设置。
8. “立即完成”只把同一报告收束到最终视觉状态，并且只发出一次完成信号。

## 播放速度

持久化选项：

- `normal`：正常逐项播放；
- `fast`：默认以快速速度播放；
- `instant`：提交后立即呈现完整正式结果。

正常或快速播放时，结算面板提供：

- `2× 加速`：仅影响当前播放，不改持久化设置；
- `立即完成`：跳过剩余表现。

## 表现与无障碍

### 降低闪光

- 默认表现只允许在结算面板和当前来源附近使用局部亮度脉冲，禁止全屏白闪。
- 开启降低闪光后，完全取消亮度脉冲，改用稳定边框、文字、符号和状态标签。

### 关闭屏幕扭曲

- 默认结算表现可使用轻微、短时的局部位移或缩放。
- 开启后不使用位移、缩放或晃动，只保留透明度、边框和文字变化。
- 该设置作为共享表现策略，供后续区域转换和庄家演出复用。

### 非颜色信息

- 生效与失效使用文字和符号区分。
- 镜像副本继续显示“镜像”文字和来源槽位，不以青色作为唯一线索。
- 颜色只作为辅助强调。

## 界面缩放

持久化选项为 `100%`、`110%`、`125%`，默认 `100%`。设置立即应用并保存。

所有档位必须在逻辑画布 1920×1080、开发窗口 1280×720 和 1920×1080 下保持核心操作、设置控件和结算轨迹可见。若引擎级缩放无法同时满足这一合同，不以“只放大字体”冒充完成，而是保留安全档位并报告验证证据。

## 设置兼容

- 设置配置新增 `accessibility` 分区。
- 缺失新字段的旧版配置按字段级默认值补齐。
- 未知或非法单个字段只回退该字段。
- 正常旧配置不视为解析损坏，不覆盖原文件。
- 写入继续使用临时文件、备份和替换流程。

## 场景边界

- 稳定的标题、状态、播放按钮与无障碍控件写入 `.tscn`。
- 动态事件行由脚本按报告内容创建。
- UI 不直接访问 `ConfigFile`、`AudioServer` 或解析器。

## 验收

- 预览事件签名、提交事件签名和播放事件签名一致。
- 正常、快速、立即与手动跳过均得到相同最终总计。
- 播放完成信号恰好一次。
- 降低闪光和关闭扭曲能改变实际播放表现，而非无效开关。
- 设置持久化与旧配置兼容通过。
- 真实指针可切换无障碍页、修改设置、加速和跳过结算。
- 1280×720 与 1920×1080 无关键裁切。
