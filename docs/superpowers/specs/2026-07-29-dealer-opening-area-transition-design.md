# 庄家开场语与区域转换叙事设计

日期：2026-07-29  
状态：已确认

## 目标

用短篇、可立即确认的叙事卡补齐三名庄家开场语和连续远征的区域转换叙事。叙事强化公开信息、预演和确定性破解，不改变计分、规则、奖励、构筑继承或存档边界。

## 边界

- 不制作分支剧情、逐句对话、语音、角色关系或叙事奖励。
- 每个边界只显示一张叙事卡，一次点击进入玩法。
- 规则文本继续来自 `DealerDefinition.rule_text`，叙事卡不替代公开规则。
- 独立区域试玩不显示跨区叙事，但显示庄家开场语。

## 内容归属

### AreaDefinition

每个区域提供远征叙事字段：

- `expedition_entry_title`
- `expedition_entry_text`

第一地区的字段描述进入远征；后续地区的字段描述固定顺序下的跨区转换。远征宿主从当前区域资源读取文案，不根据节点路径或页面文字推断内容。

### DealerDefinition

每名庄家提供：

- `opening_text`

开场卡同时显示庄家名称、开场语和现有 `rule_text`。

## 远征区域转换

1. 新远征进入金线回廊前显示首区叙事卡。
2. 完成区域并确认继续后：
   - 先原子推进 `ExpeditionSession`；
   - 保存新的区域边界；
   - 再显示目标区域叙事卡；
   - 玩家确认后才挂载目标区域场景。
3. 叙事卡显示继承摘要：
   - 牌组张数；
   - 情报券；
   - 已安装刻印数量。
4. 若进程在叙事卡期间结束，新区域已经处于可恢复的空检查点边界；继续远征时重新显示该卡。
5. 若当前区域已有非空检查点，继续远征直接恢复玩法，不重复区域卡。
6. 叙事卡提供“进入区域”和“安全返回入口”；安全返回不清除远征存档。
7. 最终区域完成后直接进入远征总结，不再伪造一个不存在的下一区域转换。

## 庄家开场

1. 区域进入庄家阶段并绑定庄家遭遇后显示开场卡。
2. 当前区域实例中只显示一次；后续轮次重绑不重复。
3. 庄家入口检查点恢复会创建新的区域实例，因此重新显示开场，确保规则上下文完整。
4. 玩家确认开场卡后才触发庄家区域提示，避免两层遮罩竞争。
5. 开场卡不修改 `AreaRunSession`，不发奖励，也不保存额外半房间状态。

## 无障碍与反馈

- 卡片信息不依赖颜色。
- 打开使用现有 `page_transition` 音效，不增加语音。
- “降低闪光”取消卡片亮度脉冲。
- “关闭屏幕扭曲”取消卡片位移和缩放。
- 设置层保持可访问并高于叙事卡。

## 已确认文案

### 金线回廊

“梦层入口合拢，金线把地面分成可核验的路径。这里不收下注，只承认你能解释的选择。”

### 金线回廊 → 反照牌厅

“铁算盘的账页封存，直线在出口处折回。你带走的牌、情报券与刻印穿过镜面，没有一项被重置。”

### 反照牌厅 → 无面中枢

“镜面碎成无名的索引，倒影失去主人。你保留全部构筑，下一位庄家则把三轮规则提前摊开。”

### 铁算盘

“六颗骰子，三张规则台，一笔不能含糊的账。把每颗骰子放到你愿意负责的位置——空着的，照样记在账上。”

### 镜面夫人

“你在右边落下的答案，会从左边看回来。别问哪一面是真的；先证明你看得懂它们为何相同。”

### 无面主人

“名字会变，次序会变，限制也会在你选择后才有意义。但没有一条规则藏在面具后面——三轮都在这里。”

### 最终结语

“三位庄家的规则都已留下可复核的轨迹。你没有靠运气赢走筹码；你证明了公开规则可以被理解、预演并拆解。”

## 验收

- 三个区域和三名庄家的叙事字段均非空并通过目录校验。
- 新远征、两次跨区和空检查点恢复显示正确区域卡。
- 非空检查点恢复不重复区域卡。
- 三名庄家各在每个区域实例显示一次，确认后进入原有规则提示。
- 叙事卡阻止背景玩法输入，真实指针可确认和安全退出。
- 1280×720 与 1920×1080 无裁切。
- 所有原有区域独立试玩和连续远征流程继续通过。
