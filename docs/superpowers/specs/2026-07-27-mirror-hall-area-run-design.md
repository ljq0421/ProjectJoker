# 《六面诡局》反照牌厅独立地区设计规格

> 文档日期：2026-07-27
> 上位规格：`2026-07-24-six-sided-rulebreakers-design.md`
> 适用引擎：Godot 4.6.1
> 交付形态：独立完整地区切片
> 状态：设计已确认

## 1. 目标

本阶段实现《六面诡局》第二地区“反照牌厅”，用于验证以下能力：

1. 同一套地区阶段机可承载不同房间、庄家、初始构筑和奖励。
2. 结算方向成为公开、可预览、可构筑的策略变量。
3. 每轮第一张合格桌间槽手法牌可生成确定性的弱化镜像副本。
4. 原牌、镜像、规则台与庄家效果共享同一份预览和正式结算路径。
5. 新手指引只教授反照牌厅新增机制，不重复基础三轨操作。
6. 现有金线回廊、铁算盘原型、基础教程、设置和音效保持兼容。

本阶段使用固定教学构筑并从主入口独立进入，不读取金线回廊完成状态，
也不实现跨地区连续单局。

## 2. 非目标

本阶段不包含：

- 金线回廊到反照牌厅的自动衔接。
- 跨地区存档、恢复或失败回滚。
- 第三地区“无面中枢”与“无面主人”。
- 一次性补齐四十张手法牌、十八张基础规则台和十二种刻印。
- 新的基础拖骰、校准、用牌、撤销或确认教程。
- 强制玩家按指定步骤使用某张手法牌。
- 隐藏概率、随机镜像、随机封禁或现实赌博导向表达。
- 把镜像结果交给 UI、动画或庄家表现层自行计算。

## 3. 已确认的产品决策

- 采用可配置地区框架，不复制第二套完整阶段机。
- 反照牌厅为独立完整地区，不立即接入连续两地区单局。
- 使用固定牌组、固定种子、固定初始资源和一个预装刻印。
- 地区包含两次选路、两个普通房、两次商店、镜面夫人、奖励和完成页。
- 每张可镜像手法牌显式声明自己的弱化镜像效果。
- 新手指引使用三个一次性情境提示，不强迫玩家完成指定操作。
- 地区完成后选择三项镜像主题刻印奖励之一，然后结束独立切片。

## 4. 地区流程

反照牌厅复用以下阶段：

```text
第一次选路
  → 第一个普通房（三轮）
  → 第一次商店
  → 第二次选路
  → 第二个普通房（三轮）
  → 第二次商店
  → 镜面夫人（三轮）
  → 刻印奖励
  → 安装刻印
  → 地区完成
```

失败规则与金线回廊一致：

- 任一遭遇三轮结束后未达到累计目标，地区进入失败状态。
- 失败页说明目标差值、失效规则和未利用资源。
- 重开恢复固定初始构筑与固定种子。
- 重试、重开和失败页不自动重播已请求的新手提示。

## 5. 固定教学构筑

独立入口使用以下初始状态：

- 固定种子：`20260727`。
- 十二张固定手法牌。
- 至少三张牌的目标类型为桌间槽，并拥有不同的 `mirror_effects`。
- 首轮固定洗牌结果至少包含一张可镜像桌间槽牌。
- 六颗标准骰子。
- 初始情报券：`6`。
- 预装刻印：桥接类刻印，安装在 `d3` 的 `4` 面。
- 每轮仍只有两个校准点和最多两次真实出牌机会。

镜像副本不是一次真实出牌，因此：

- 不减少手牌。
- 不进入弃牌堆。
- 不占用第二次出牌机会。
- 不占用实体桌间槽。
- 不增加商店牌组容量。

固定构筑只服务独立第二地区测试。未来连续单局接入后，
`RunDirector` 可以用上一地区完成快照替换这份初始状态。

### 5.1 十二张起始牌组

固定起始牌组按以下 ID 装载，不从全局 starter 池临时抽取：

```text
starter_nudge_up_1
starter_nudge_down_1
starter_map_1
starter_map_2
starter_repeat_1
starter_stable_repeat
starter_amplified_repeat
starter_link
starter_reverse
mirror_folded_map
mirror_soft_echo
mirror_hinged_bridge
```

固定种子 `20260727` 的首轮四张手牌必须至少包含
`mirror_folded_map`、`mirror_soft_echo`、`mirror_hinged_bridge` 之一。
测试只断言“至少出现一张可镜像牌”，不把整个首轮手牌顺序写死，
避免以后调整洗牌实现时无意义地重写验收。

### 5.2 商店池

反照牌厅只从以下六张牌生成商店候选：

```text
mirror_double_exposure
mirror_deep_echo
mirror_silver_bridge
shop_precision_map
shop_triple_repeat
shop_amplified_chain
```

每次商店从“不在当前牌组内”的候选中按地区 RNG 洗牌并公开前三张，
单张价格沿用 `1` 情报券。已买入牌因已在牌组中，不得在第二次商店再次出现。
离开第一次商店前必须仍能保证第二次商店至少有三张合法候选；
若实现允许一次商店买入三张，则六张候选正好覆盖两次商店的最坏情况。

## 6. 普通房内容

新增四个房间资源，分成两组选路。

### 6.1 第一次选路

两条路线都保证玩家能在镜面夫人前接触镜像机制。

#### 逆序校场

- 结算方向：从右向左。
- 镜像规则：启用。
- 重点：先读方向，再规划三轨顺序。
- 初始累计目标：`110`。
- 精解情报券：`5`。

#### 双影账页

- 结算方向：从左向右。
- 镜像规则：启用。
- 重点：比较原牌与镜像副本落在不同桌间槽后的结果。
- 初始累计目标：`116`。
- 精解情报券：`6`。

### 6.2 第二次选路

#### 回声桥

- 结算方向：从右向左。
- 镜像规则：启用。
- 重点：相邻传递与弱化重复结算。
- 初始累计目标：`132`。
- 精解情报券：`7`。

#### 对称账页

- 结算方向：从左向右。
- 镜像规则：启用。
- 重点：在两个桌间槽之间安排不同来源的真实牌与虚拟副本。
- 初始累计目标：`140`。
- 精解情报券：`8`。

这些是首轮设计数值。只有确定性可玩性审计证明某条路线经常无解、
唯一解或明显失衡时才允许调整；调整必须保持
`110 < 116 < 132 < 140 < 镜面夫人目标` 的难度顺序。

## 7. 镜面夫人

新增 `dealer_mirror_lady`。

### 7.1 公开规则

- 三轮累计目标：`190`。
- 固定从右向左结算。
- 每轮第一张放入桌间槽的合格手法牌生成一个公开的弱化镜像副本。
- 镜像副本使用卡牌资源中的 `mirror_effects`。
- 镜像副本不能继续生成副本。
- 原牌撤销、收回或被重做时，副本同步变化。
- 所有副本参数、槽位和事件顺序在确认前显示。

### 7.2 设计目的

镜面夫人检验：

- 玩家是否先阅读结算方向。
- 玩家是否理解原牌与镜像槽位的空间关系。
- 玩家是否能比较真实牌、虚拟副本和第二次真实出牌的组合。
- 玩家是否能通过撤销和重做重新安排完整方案。

镜面夫人不随机封禁牌、骰子、花色或刻印。

## 8. 镜像副本语义

### 8.1 合格牌

只有同时满足以下条件的牌可以生成镜像：

- `target_type` 为桌间槽。
- `mirror_effects` 非空。
- 当前遭遇的 `mirror_first_table_card` 为 `true`。
- 本轮尚未生成镜像副本。
- 当前操作通过全部原牌和副本校验。

没有 `mirror_effects` 的桌间槽牌仍可正常使用，但不会消耗本轮镜像机会。
本轮镜像机会由第一张实际生成副本的合格牌消耗。

### 8.2 槽位映射

```text
left_gap  ↔ right_gap
```

端点随空间一起反照，不沿用原牌的物理左右顺序：

```text
原牌 left → middle  时，镜像为 right → middle
原牌 middle → right 时，镜像为 middle → left
```

其中箭头左侧写入 `primary_target`，右侧写入 `secondary_target`。
因此 `LINK_NEIGHBORS` 的来源与去向都会被反照，而不是只把同一条
左到右连接平移到另一个槽位。

副本使用虚拟槽层：

- 可以与实体牌同时显示在同一槽附近。
- 不阻止玩家把第二张真实牌放入该槽。
- 不接受单独选择、拖动、撤销或目标修改。
- 其生命周期完全依附原牌。

### 8.3 效果限制

首批 `mirror_effects` 只允许：

- `MODIFY_COEFFICIENT`
- `REPEAT_TABLE`
- `LINK_NEIGHBORS`

首批禁止：

- `ADJUST_DIE`
- `REVERSE_RESOLUTION`

禁止原因：

- 骰子调整缺少稳定的镜像骰目标。
- 镜像反转会产生双重方向重写，降低结算轨迹可读性。

未来若要开放这些效果，必须先新增明确目标映射和独立设计规格。

### 8.4 桌间牌的单桌目标约定

为使同一张桌间牌能够组合连接、系数与复写效果，扩展通用效果语义：

- `LINK_NEIGHBORS` 读取 `primary_target` 和 `secondary_target`。
- 桌间牌上的 `MODIFY_COEFFICIENT` 作用于 `secondary_target`。
- 桌间牌上的 `REPEAT_TABLE` 作用于 `secondary_target`。
- 规则台牌上的后两种效果仍作用于 `primary_target`，现有内容不变。

内容校验器相应允许 `MODIFY_COEFFICIENT` 和 `REPEAT_TABLE`
出现在 `TABLE` 或 `GAP` 牌中，但 `GAP` 牌必须同时具有两个合法相邻端点。
UI 文案统一使用“箭头所指规则台”，不使用容易受结算方向干扰的
“下一张规则台”。

### 8.5 事件顺序

镜像副本作为派生 `PlayedCard` 参与模拟：

1. 玩家放置原牌。
2. `MirrorCopyResolver` 校验并生成副本。
3. 原牌和副本按各自所在桌间槽进入空间结算顺序。
4. `RoundResolver` 生成带来源信息的事件列表。
5. UI 根据事件列表显示原牌与镜像来源。
6. 正式提交复用同一报告。

副本不会在步骤 2 再次经过镜像生成逻辑。

- `display_name`

- `second_route_ids`
- `rooms`

- `starting_intel_tickets`
- `initial_engraving_id`

- `shop_offer_ids`
- `engraving_offer_ids`

### 9.2 `AreaRunSession`

`AreaRunSession` 改为消费 `AreaDefinition` 和通用内容目录，不再声明
`GoldCorridorCatalog` 类型。

保留现有阶段、失败、重开、商店、奖励和完成接口。

以下内容必须由地区定义提供：

- 路线组。
- 房间资源。
- 庄家 ID 和目标。
- 初始牌组、资源和刻印。
- 商店与奖励池。

`GoldCorridorRunScreen` 和现有测试继续通过兼容构造器或金线地区定义工作。

### 9.3 共享 `AreaRunScreen`

提取共享地区 UI 编排：

- 路线选择。
- 三轮遭遇。
- 商店。
- 庄家。
- 奖励。
- 失败、重开、返回和完成。

地区差异通过显式配置和小型适配器提供。

稳定布局继续保存在 `.tscn`：

- `area_run_screen.tscn` 保存共享结构。
- `gold_corridor_run_screen.tscn` 保留兼容入口。
- `mirror_hall_run_screen.tscn` 提供反照牌厅入口和地区特有方向/镜像显示。

不得在脚本中运行时拼装整张地区界面。

### 9.4 未来扩展

本阶段不实现 `RunDirector`。

`AreaRunSession.completion_snapshot()` 必须保留未来连续单局需要的：

- 牌组。
- 情报券。
- 骰子与刻印。
- 随机状态。
- 地区 ID。
- 已获奖励。

本阶段只在完成页展示这份快照。

## 10. 结算数据模型

### 10.1 `EncounterRuleProfile`

新增资源：

- `resolution_direction`
- `mirror_first_table_card`
- `mirror_limit_per_round`

首批 `mirror_limit_per_round` 固定为 `1`，字段存在是为了校验和可读性，
不是为了在本阶段制作多重镜像内容。

### 10.2 `CardDefinition`

增加：

```gdscript
@export var mirror_effects: Array[EffectSpec] = []
```

资源文本必须同时说明原效果和镜像效果。

### 10.3 `PlayedCard`

增加：

- `play_id`
- `is_mirror_copy`
- `source_card_id`
- `source_play_id`
- `source_slot_id`

真实牌与副本具有不同运行时实例，但副本必须能追溯到唯一原始操作。

### 10.4 `MirrorCopyResolver`

职责：

- 判断牌是否合格。
- 映射相对槽位。
- 深复制 `mirror_effects`。
- 创建不可递归的派生 `PlayedCard`。
- 返回结构化成功或失败原因。

它不读取场景节点，不显示 UI，也不直接修改正式状态。

### 10.5 `ResolutionEvent`

增加镜像来源信息，至少能够表达：

- 事件是否来自镜像。
- 原牌 ID。
- 原槽位和镜像槽位。

玩家可见标签使用“镜像副本：牌名”，不依赖颜色区分。

## 11. 原子性与错误处理

### 11.1 出牌

出牌采用全有或全无：

- 原牌非法：不改变状态。
- 镜像参数非法：不改变状态。
- 镜像槽映射非法：不改变状态。
- 事件生成失败：不改变状态。

不能只保留原牌并静默丢弃副本。

### 11.2 内容加载

内容校验器拒绝：

- 未知镜像操作。
- 不允许的镜像操作。
- 缺少桌间槽目标。
- 无法映射的槽 ID。
- 空 ID、重复 ID 或空中文规则文本。
- 镜像副本再次声明镜像来源。

开发构建在内容错误存在时阻止进入地区，并显示资源路径和字段。

### 11.3 提交

- 正式提交前重新验证镜像来源和目标。
- 预览报告与正式报告不一致时拒绝提交。
- 任何派生引用失效都恢复提交前状态。
- 镜像副本不改变牌组抽取、弃牌或商店记录。

### 11.4 引导

- 引导配置损坏时保留原文件。
- 写入失败时关闭提示并显示瞬时警告。
- 目标缺失时不打开部分遮罩，也不标记已读。
- 引导交互不得修改牌组、骰子、RNG、回合、报告、商店或奖励状态。

## 12. 新增内容

本阶段新增：

- 六张镜像主题手法牌。
  - 三张进入固定初始牌组。
  - 三张进入反照牌厅商店池。
- 四个普通房资源。
- 一个镜面夫人资源。
- 四种镜像主题刻印。
- 一个反照牌厅地区定义。

### 12.1 六张手法牌

所有新牌的 `target_type` 均为 `GAP`，并明确填写 `effects` 和
`mirror_effects`。下表中的“目标”均指箭头所指的 `secondary_target`。

| ID | 名称 | 来源 | 原牌效果 `effects` | 镜像效果 `mirror_effects` |
| --- | --- | --- | --- | --- |
| `mirror_folded_map` | 折光映射 | 起始牌组 | 目标系数 `+2` | 反照目标系数 `+1` |
| `mirror_soft_echo` | 轻声复写 | 起始牌组 | 目标额外结算 `2` 次 | 反照目标额外结算 `1` 次 |
| `mirror_hinged_bridge` | 合页桥 | 起始牌组 | 连接两端，并令目标系数 `+1` | 只连接反照后的两端 |
| `mirror_double_exposure` | 双重曝光 | 商店 | 目标系数 `+2`，并额外结算 `1` 次 | 反照目标系数 `+1` |
| `mirror_deep_echo` | 深层回声 | 商店 | 目标系数 `+1`，并额外结算 `2` 次 | 反照目标额外结算 `1` 次 |
| `mirror_silver_bridge` | 银面长桥 | 商店 | 连接两端，并令目标额外结算 `1` 次 | 只连接反照后的两端 |

对应资源文案必须同时写出原牌和弱化副本，例如：

> 折光映射：令箭头所指规则台的系数 +2。镜像：反照后目标的系数 +1。

“额外结算 2 次”对应 `REPEAT_TABLE amount = 2`，不是总共结算两次。
`LINK_NEIGHBORS amount` 继续固定为 `1`。

### 12.2 四种刻印

四种新刻印只进入反照牌厅奖励池：

| ID | 名称 | 操作 | 规则 |
| --- | --- | --- | --- |
| `engraving_afterimage` | 余像 | `ECHO_ADJACENT` | 刻印面激活且规则台通过时，获得较高相邻骰的完整点数；`amount = 1`。 |
| `engraving_silver_anchor` | 银锚 | `ANCHOR_DIE` | 刻印面激活后不能校准或被点数牌修改；规则台通过时固定 `+3`。 |
| `engraving_backflow_bridge` | 逆流桥 | `BRIDGE_BACKWARD` | 刻印面激活且规则台通过时，把该骰有效点数传递给结算顺序中的上一张有效规则台。 |
| `engraving_mirror_prism` | 镜棱 | `MIRROR_PRISM` | 刻印面激活，且所在规则台与本轮镜像副本相邻时，在奇偶条件中同时视为奇数与偶数。 |

`BRIDGE_BACKWARD` 和 `MIRROR_PRISM` 是
`EngravingDefinition.Operation` 的新增显式枚举值，不通过标签或名称判断。
“结算顺序中的上一张”以公开方向生成的 `ordered_rule_ids` 为准；
若不存在上一张，产生 `0` 分、`effect_applied = false` 的可见事件。
`MIRROR_PRISM` 必须从本轮派生 `PlayedCard` 判断相邻关系，
不得从 UI 镜像节点是否存在来判断。

### 12.3 刻印奖励

镜面夫人成功后，地区 RNG 只从上述四种新刻印中无放回选出三种。
同一固定种子与同一操作序列必须生成相同三项及相同顺序。
玩家选择一项并安装后直接进入地区完成页；未被选中的刻印不写入完成快照。

实现后仓库的最低内容数量为：

- 手法牌：`24`。
- 普通房：`8`。
- 庄家：`2`。
- 刻印：`8`。

这些数量仍低于最终垂直切片目标，剩余内容在后续阶段补齐。

## 17. 完成标准
