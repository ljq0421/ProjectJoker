# 《六面诡局》骰子优先单遭遇原型合同

## 验证目标与边界

本原型验证六骰天然组合、一次有代价的选择性重投、一条改变重投取舍的“组合升级奖励”规则、一组真正改变骰子空间操作的公开随机行为规则台，以及一次可预测破局。它从主菜单试玩入口进入，不接管三区正式远征、不写远征存档，也不修改 `CardDefinition`、既有卡牌资源或正式 `RoundResolver` 的输入形状。

视觉继续使用 Dream Glass。骰子和组合轨道是第一视觉层，重投取舍与左右台分配是决策层，改骰指令是结算前的窄条工具。试玩界面只使用玩家能直接理解的动作，不新增扑克牌型。

## 状态与随机边界

状态严格按 `等待投掷 → 重投决策 → 确定调整 → 已提交` 前进。

- 初投发生在任何玩家决策前。
- 初投后解析器记录所有具体初始组合，例如“一对 3”“三个 5”“1–4 连续”。玩家不需要声明或锁定目标。
- 玩家可保留全部，或直接选择 1–3 颗进行唯一一次重投；没有选择的骰子自然保持不变。每颗重投骰公开扣 `2` 分和 `1` 点破局能量；没有保底或隐藏补偿。
- 重投完成后，改骰、破局预演和提交都不再调用随机数。
- 预览与提交读取同一份 `DiceFirstResolver` 报告；UI 不自行计算分数、组合、升级、能量或破局增量。

## 组合合同

解析器使用改写后的最终骰值，按固定顺序报告：

1. **三个相同**：任一点数至少出现 3 次，`+2` 能量、`+10` 分；同点数不再重复报对子。
2. **一个对子**：至少一个点数恰好出现 2 次，`+1` 能量、`+4` 分。
3. **四个连续**：至少 4 个不同点数连续，`+2` 能量、`+8` 分。
4. **三对都凑成 7**：六骰能拆成 3 对且每对和为 7，`+3` 能量、`+12` 分。

同点组合只做互斥降重；连续与凑 7 可以连锁。初始组合必须指向具体骰子，而不是只记录组合类型；同一投骰若同时有“一对 3”和“一对 5”，解析器必须分别记录，UI 必须随当前重投选择说明哪个不动、哪个会被拆散。

## 组合升级奖励

本原型没有锁定按钮和锁定状态。玩家未选择重投的骰子自然不动；这已经足以保护已有组合，不再增加一次重复声明。

确认重投时，控制器保存初投解析器列出的所有具体组合。一个初始组合只有在其具体骰子都没有被重投时才算“未拆散”；最终结果相对该组合发生以下确定升级时，获得一次 `+1` 连锁能量：

- 相同点数组合包含更多同值骰，例如“一对 3”升级为“三个 3”。
- 连续组合长度增加，例如“四个连续”升级为“五个连续”。
- “三对都凑成 7”已经是本原型终点，不再提供升级能量。

升级可以来自唯一一次重投，也可以来自结算前唯一一条改骰指令。同局即使有多个初始组合升级，也只奖励一次；解析器按初始组合公开列表顺序选择首个升级项。若重投触碰了初始组合中的任一具体骰子，该组合即使最终碰巧恢复同样点数，也不能领取升级奖励。

## 行为规则台池、改骰与破局

三条运行时改骰指令为 `翻到另一面 7−n`、`点数 +1`、`点数 −1`，仍通过 `CardDefinition → PlayedCard → EffectSpec` 进入解析路径。每局最多执行一条。

初投六骰时同时从三个行为规则中公开确定本局规则；规则选择与骰值都由同一种子复现，并且发生在任何重投、改骰或分配决策之前。重投决定后，六颗骰子必须全部分配到左右两张规则台，每台恰好三颗。玩家先选择骰子，再执行“放入左台”“放入右台”或“收回”；规则台已满时拒绝第四颗骰子，不静默替换。

规则池为：

- **跨台共振**：左右出现同一点数时，该点数再计一次，每组获得 `+1` 能量。
- **极性回路**：左右骰子之和为 `7` 时，其中较高点再计一次，每组获得 `+1` 能量。
- **蓄能台**：右台三骰从基础分中封存；每种不同点数获得 `+1` 能量，三骰全异时左台最高点再计一次。

前两类规则由解析器自动寻找“匹配组数最多，其次奖励分最高，最后骰子 ID 顺序最小”的稳定跨台配对。玩家只决定左右分组，不需要再手工排序三组连线。蓄能台不进行配对，直接形成分数与能量取舍。所有扣分、重计和充能都进入正式 `ResolutionEvent`，而不是只改最终总数。规则台未完成 `3 + 3` 分配时不能破局或提交。

总分为 `六骰点数 + 组合奖励 + 规则台净变化 − 重投代价 + 破局增量`。能量为 `组合能量 + 升级能量 + 规则台能量 − 重投能量代价`，最低为 0。

能量至少 `2` 且存在有效组合时，可预演一次破局：解析器在组合骰中按“最终点数最高、同点时骰子编号最小”选择一颗，额外计一次它的点数。第一次点击加入预览，第二次撤销；确认结算前不提交。

## 界面语言和渐进展示

试玩界面只使用：`选择 1–3 颗骰子重投`、`不动`、`会拆散`、`组合升级 +1能量`、`破局`。组合直接写作“三个相同、一个对子、四个连续、三对都凑成 7”。不展示旧版“拿额外分、保住组合、锁定组合、兑现、迁徙、共鸣、镜面越界”等术语。

投掷前不展示后续构筑；初投后立即展示本局规则台和当前组合，并随骰子选择即时展示哪些组合不动、哪些会拆散；重投结束后展示组合升级、左右分配、规则台实时结果、可选改骰、本次结算和破局。该渐进展示不替代未来融合正式远征时的新手引导。

## 后续候选规则，不进入本轮实现

- **吞噬台**：牺牲一颗骰子，换取另一台倍率或骰位变化。
- **迁徙台**：结算事件把骰子推向另一台，并可能二次触发条件。
- **裂变台**：特定骰面拆成两个虚拟值，改变槽位与关系判断。
- **跨轮蓄能**：本轮封存、下一轮释放；只适合未来接入多轮正式遭遇。

这些候选需要新的虚拟骰、跨轮状态或事件迁移合同，不能只靠增加规则文案实现，因此在当前单遭遇原型中保持未实现。

## 验收路径

真实鼠标路径覆盖：进入原型、投骰并看到公开规则、直接选择骰子、查看“不动/会拆散”的组合后果、重投、执行改骰使未拆散组合升级、通过真实按钮把六骰分配为左三右三、查看规则台实时结果、破局预演/撤销/再次预演、提交、重开。领域测试覆盖全部三类规则；真实鼠标夹具固定使用跨台共振以保证输入路径稳定。领域测试、全量 headless、GPU 非 headless 输入、截图视觉检查和真人试玩分别报告。
