# 《六面诡局》无面中枢独立地区设计规格

> 文档日期：2026-07-27
> 上位规格：`2026-07-24-six-sided-rulebreakers-design.md`
> 适用引擎：Godot 4.6.1
> 交付形态：独立完整地区切片
> 状态：设计已确认

## 1. 目标

本阶段实现《六面诡局》第三地区“无面中枢”，用于验证以下能力：

1. 同一场三回合遭遇可按资源计划逐回合切换公开规则。
2. 第二回合后可暂停会话，让玩家主动选择第三回合限制。
3. 操作限制和分配限制进入统一合法性、预演和正式结算路径。
4. 已学过的点数、方向、桌间联动和镜像规则可以组成可读的复合遭遇。
5. 固定后期样板构筑可以独立验证第三地区，而不依赖尚未实现的连续远征。
6. 手法牌补齐花色、牌面和稀有度元数据，并扩展到四十张。
7. 刻印扩展到十二种，庄家扩展到三名。
8. 三个一次性情境提示只教授无面中枢新增机制。
9. 现有金线回廊、反照牌厅、基础教程、设置和音效保持兼容。

本阶段继续坚持：

- 所有规则在确认前公开。
- 所有效果确定执行。
- 所有代价与非法原因可见。
- 不添加下注、加注、追损、借贷或概率触发奖励。

## 2. 非目标与规格边界

本阶段不包含：

- 金线回廊、反照牌厅和无面中枢的连续三区域远征。
- 跨区域生命、商店、牌组和随机状态继承。
- 三地区九场遭遇的完整单局。
- 稀有手法牌与刻印的混合奖励选择界面。
- 第三个刻印槽。
- 中途保存半轮或“等待限制选择”状态。
- 随机隐藏规则、随机封禁花色或随机选择最终限制。
- 为每张新牌弹出独立教学窗口。
- 通过 UI、动画或庄家脚本自行判断玩法规则。

当前项目把规则台作为房间和遭遇中的嵌入资源，没有独立的十八项
`RuleTableCatalog`。因此本阶段不能仅凭重复嵌入的规则台数量宣称已经满足
“十八张基础规则台定义”。该目录化工作与完整三区域远征都属于后续阶段。

完成本阶段意味着第三地区与最终牌、刻印、庄家数量就绪，
不等于上位规格的整个垂直切片已经完成。

## 3. 已确认的产品决策

- 无面中枢先作为独立完整地区入口实现。
- 采用资源驱动的通用回合计划，不制作无面主人专用 UI 规则脚本。
- 地区包含两组选路、四个普通房资源、两次商店、无面主人、刻印奖励和完成页。
- 每组选路只进入其中一个普通房，因此一次地区流程仍经历两个普通房。
- 使用固定十二张跨区域牌组、较高初始情报和一个预装刻印。
- 无面主人三回合的规则从开战起全部公开。
- 第二回合结束后，玩家从一个操作限制和一个分配限制中选择。
- 选择只作用于第三回合，确认后不可更换。
- 击败无面主人后安装第二个刻印，不增加混合奖励界面。
- 新手指引使用三个一次性情境提示。
- 新牌通过规则文案、合法目标高亮和具体非法原因教学。

## 4. 地区流程

无面中枢复用现有地区阶段机：

```text
第一次选路
  → 第一个普通房（三轮）
  → 第一次商店
  → 第二次选路
  → 第二个普通房（三轮）
  → 第二次商店
  → 无面主人（三个不同回合计划）
  → 选择无面刻印
  → 安装第二刻印
  → 地区完成
```

失败规则与现有地区一致：

- 任一遭遇三轮结束后未达到累计解析目标，地区进入失败状态。
- 失败页说明目标差值、失效规则和未利用资源。
- 重开恢复固定样板构筑与固定种子。
- 重试、重开和失败页不自动重播已经请求过的无面提示。

## 5. 固定后期样板构筑

独立入口使用以下初始状态：

- 固定种子：`20260727`。
- 十二张固定跨区域手法牌。
- 六颗标准骰子。
- 初始情报券：`8`。
- 预装刻印：`engraving_backflow_bridge`，安装在 `d3` 的 `4` 面。
- 每轮两个校准点。
- 每轮默认最多使用两张真实手法牌。
- 当前已安装刻印数量为 `1`，地区内最多再安装 `1` 个。

`8` 是首轮平衡值，比反照牌厅独立入口的 `6` 更高，用于表达后期构筑；
只有商店可玩性样本证明选择过少或资源过剩时才调整。

### 5.1 十二张起始牌组

固定牌组按以下 ID 装载：

```text
starter_nudge_up_1
starter_nudge_down_1
starter_map_2
starter_repeat_1
starter_link
starter_reverse
mirror_folded_map
mirror_soft_echo
mirror_hinged_bridge
faceless_swap_values
faceless_refund_calibration
faceless_three_seats
```

牌组构成为：

- 六张金线回廊阶段牌。
- 三张反照牌厅牌。
- 三张无面中枢牌。

固定种子只保证每场三轮看完十二张牌，不把完整抽牌顺序写死。
无面主人首轮手牌必须至少包含一张能影响方向、桌间关系或骰值的牌，
避免第一回合无法体现复合规划。

### 5.2 商店池

无面中枢商店池包含剩余十三张无面牌，以及三张未进入起始牌组的
跨区域高阶牌。每次商店继续：

- 排除已经在牌组中的牌。
- 使用地区 RNG 确定候选顺序。
- 公开三项候选。
- 购买新牌时替换牌组中的一张旧牌。
- 保持牌组容量为十二张。

具体跨区域候选在实施计划中从现有高阶牌中确定，
但不得改变“十六张无面新牌全部可以通过起始牌组或商店实际体验”的要求。

## 6. 普通房内容

新增四个普通房资源，分成两组选路。

### 6.1 第一次选路：复合规则

#### 交错档案

- 结算方向：从左向右。
- 镜像规则：关闭。
- 三张规则台分别使用精确点数、全偶和连续数。
- 重点：先读完整条件，再分配骰子与手法牌。
- 触发无面中枢第一个一次性提示。

#### 反向索引

- 结算方向：从右向左。
- 镜像规则：关闭。
- 提高右侧先结算台、桌间传递和重复效果的规划价值。
- 重点：在混合条件下重新判断空间顺序。

### 6.2 第二次选路：限制预演

#### 单手议程

- 每轮最多使用一张真实手法牌。
- 镜像生成的虚拟副本不计入数量。
- 重点：提前演练无面主人的操作限制。
- 非法原因必须显示当前真实出牌数和上限。

#### 三席协议

- 确认时三张规则台都必须至少分配一颗骰子。
- 不要求三张规则台全部通过。
- 界面持续显示覆盖进度，例如“已覆盖 2/3 张规则台”。
- 重点：提前演练无面主人的分配限制。

### 6.3 解析目标

普通房目标不在资源创作时凭直觉写死。

实施时先使用固定骰序和样板构筑枚举可行方案，再确定首轮目标值。
每个房间必须满足：

- 常见固定样本至少存在两条有意义的解决路径。
- 不依赖商店买到某一张指定牌才能通过。
- 第二组房间的目标高于第一组。
- 额外限制带来的难度通过公开情报奖励补偿。

目标与奖励的最终数值必须写回资源和实施计划验证表。

## 7. 无面主人

新增 `dealer_faceless_master`。

### 7.1 公开三回合日程

开战时一次性公开：

#### 第一回合：正面

- 从左向右结算。
- 不生成镜像副本。
- 使用三种基础条件的复合组合。

#### 第二回合：反面

- 从右向左结算。
- 不生成镜像副本。
- 改变桌间牌、重复目标和高系数台的优先级。

#### 第三回合：无面

- 恢复从左向右结算。
- 第一张合格桌间手法牌生成公开的弱化镜像副本。
- 同时应用玩家确认的最终限制。

三回合继续累计同一个公开解析目标。
目标值在两种最终限制的固定样本均通过可玩性验证后确定。

### 7.2 最终限制

两个候选从首领战开始就公开，第二回合结算后才要求选择。

#### 独手裁决

- 类型：操作限制。
- 只作用于第三回合。
- 第三回合最多使用一张真实手法牌。
- 镜像副本不计入上限。

#### 三席到场

- 类型：分配限制。
- 只作用于第三回合。
- 确认结算时，左、中、右三张规则台必须各有至少一颗骰子。
- 不满足时指出具体缺少的规则台。

选择确认后不可更换。两个限制均不改变骰子随机结果，
也不会在确认后追加隐藏惩罚。

## 8. 通用回合计划模型

### 8.1 `EncounterRoundPlan`

新增自定义 `Resource`，至少包含：

- `id`
- `display_name`
- `encounter`
- `public_summary`

`encounter` 继续持有三张规则台与 `EncounterRuleProfile`。
因此每回合可以更换规则台组合、结算方向与镜像配置，
而不把规则字段复制到会话或 UI。

### 8.2 `FinalRestrictionDefinition`

新增结构化限制资源，至少包含：

- `id`
- `display_name`
- `category`
- `rule_text`
- `operation`
- `amount`

首批类别：

- `OPERATION`
- `DISTRIBUTION`

首批操作：

- `MAX_REAL_CARDS`
- `REQUIRE_ALL_TABLES_OCCUPIED`

限制不得持有任意脚本回调。未知操作、负数上限或空规则文本在内容加载时拒绝。

### 8.3 `DealerRoundSchedule`

新增资源，至少包含：

- 三个 `EncounterRoundPlan`
- 一个操作限制
- 一个分配限制

首批严格要求恰好三个回合计划和两个不同类别的限制。
未来可以扩展数量，但本阶段不为尚未出现的需求制作通用图编辑器。

### 8.4 兼容行为

`EncounterRunSetup` 增加可选的 `round_schedule`。

- 配置日程时，按当前回合读取对应 `EncounterRoundPlan`。
- 未配置日程时，三轮继续使用现有单个 `encounter`。

金线回廊和反照牌厅不需要重写遭遇资源，
也不能因空日程改变当前行为。

## 9. 三回合会话状态

`ThreeRoundEncounterSession` 增加明确阶段：

```text
ROUND_PLAYING
AWAITING_RESTRICTION
RUN_COMPLETED
```

会话记录：

- 当前回合索引。
- 当前回合计划 ID。
- 两个公开候选限制。
- 已确认限制 ID。
- 第三回合是否已经开始。

状态转换：

```text
第一回合结束
  → 第二回合

第二回合结束
  → AWAITING_RESTRICTION
  → 玩家确认一个限制
  → 第三回合

第三回合结束
  → RUN_COMPLETED
```

处于 `AWAITING_RESTRICTION` 时：

- 不创建第三回合 `RoundState`。
- 不允许拖骰、用牌、校准、撤销、重做或确认。
- 允许读取日程、候选限制和前两回合结果。
- 只能通过合法限制 ID 继续。

选择确认后写入会话状态，再创建第三回合。
一旦第三回合开始，选择不能通过撤销或重做改变。

## 10. 限制校验与结算

第三回合输入统一经过：

```text
玩家操作
  → 基础 ActionValidator
  → 当前限制校验
  → 克隆 RoundState
  → EffectResolver 模拟
  → 生成 ResolutionEvent
  → UI 展示预演
  → 玩家确认
  → 重新校验并原子提交同一报告
```

### 10.1 操作限制

`MAX_REAL_CARDS` 在接受新牌前校验。

- 只统计 `is_mirror_copy == false` 的已用牌。
- 镜像副本不会消耗额度。
- 撤销真实牌后额度恢复。
- 重做仍需重新校验当前限制。
- 超限时不改变手牌、弃牌、槽位或预演报告。

### 10.2 分配限制

`REQUIRE_ALL_TABLES_OCCUPIED` 在确认本轮时校验。

- 玩家仍可自由拖动、收回和重新分配骰子。
- 限制只阻止不完整方案正式提交。
- 错误必须列出缺少骰子的规则台。
- 拒绝提交时保持整个回合状态不变。

### 10.3 预览一致性

限制结果进入与基础合法性相同的结构化报告。

- UI 不根据按钮状态推断规则。
- 庄家动画不修改限制结果。
- 正式提交前重新校验限制。
- 预览报告与正式报告不一致时拒绝提交并恢复状态。

## 11. 卡牌模型补全

当前 `CardDefinition` 没有花色、牌面和稀有度字段。
本阶段为全部四十张牌增加：

```gdscript
enum Suit {
    CLUBS,
    HEARTS,
    DIAMONDS,
    SPADES,
}

enum Rarity {
    COMMON,
    UNCOMMON,
    RARE,
}

@export var suit: Suit
@export var rank_label: String
@export var rarity: Rarity
```

要求：

- 四种花色各十张。
- 花色图形同时提供文字或无颜色图标。
- 牌面点数只表达强度与稀有度，不组成传统牌型。
- 内容校验拒绝空牌面、未知花色和重复 ID。
- 现有二十四张牌原则上不改变实际效果，只补齐元数据。
- 混合效果牌按主要策略用途归类，不能只为凑数量使用违背规则文本的花色。

## 12. 十六张无面手法牌

### 12.1 梅花：骰值重构

| ID | 名称 | 目标 | 规则 |
| --- | --- | --- | --- |
| `faceless_swap_values` | 换位 | 两颗骰子 | 交换两颗骰子的当前点数。 |
| `faceless_copy_value` | 复刻 | 来源骰、目标骰 | 令目标骰复制来源骰的当前点数。 |
| `faceless_flip_value` | 翻面 | 一颗骰子 | 当前点数变为 `7 - 当前点数`。 |
| `faceless_lock_bonus` | 定格 | 一颗骰子 | 本轮不能再修改；所在规则台通过时获得固定奖励。 |

新增结构化效果原语：

- `SWAP_DICE`
- `COPY_DIE`
- `FLIP_DIE`
- `LOCK_DIE_WITH_BONUS`

双骰目标使用明确的主、次目标，不从选中顺序或场景节点推断。

### 12.2 红桃：容错与恢复

| ID | 名称 | 目标 | 规则 |
| --- | --- | --- | --- |
| `faceless_refund_calibration` | 校准回收 | 全局 | 返还一个已使用的校准点。 |
| `faceless_exact_tolerance` | 精确宽限 | 精确点数台 | 目标值上下相差一也可通过。 |
| `faceless_even_tolerance` | 奇偶宽限 | 全偶台 | 允许其中一颗骰为奇数。 |
| `faceless_sequence_tolerance` | 序列宽限 | 连续数台 | 允许出现一个间隔为二的缺口。 |

新增结构化效果原语：

- `REFUND_CALIBRATION`
- `MODIFY_CONDITION`

`MODIFY_CONDITION` 使用枚举参数，不允许规则文本脚本。
只有与当前规则台条件匹配的宽限牌才显示为合法目标。

### 12.3 方片：情报效率

| ID | 名称 | 目标 | 规则 |
| --- | --- | --- | --- |
| `faceless_table_receipt` | 核验凭证 | 规则台 | 指定台通过后获得一情报。 |
| `faceless_full_allocation` | 满骰记录 | 全局 | 本轮分配全部六颗骰后获得二情报。 |
| `faceless_three_seats` | 三席记录 | 全局 | 三张规则台均有骰子后获得二情报。 |
| `faceless_complete_dossier` | 完整卷宗 | 全局 | 三张规则台全部通过后获得三情报。 |

新增 `GRANT_INTEL_ON_CONDITION`。

- 预演显示“预计获得”。
- 只有正式提交成功后入账。
- 撤销、失败或被拒绝的提交不入账。
- 同一正式报告只能兑现一次。
- 奖励事件必须进入结算轨迹。

### 12.4 黑桃：公开代价与连锁

| ID | 名称 | 目标 | 规则 |
| --- | --- | --- | --- |
| `faceless_strict_mapping` | 加严映射 | 规则台 | 所需骰位加一，同时系数加二。 |
| `faceless_reverse_replay` | 逆序重演 | 桌间槽 | 反转方向，并令箭头所指规则台额外结算一次。 |
| `faceless_compressed_repeat` | 压缩复写 | 规则台 | 系数减一，额外结算两次。 |
| `faceless_closed_circuit` | 闭环传递 | 桌间槽 | 连接两端，并令箭头所指规则台额外结算一次。 |

`faceless_strict_mapping` 只有在：

- 规则台骰位尚未达到上限；
- 增加骰位后整局仍存在合法分配容量；
- 当前牌与限制均允许使用；

时才是合法目标。

本批牌不增加重投效果，避免把无面中枢的策略重点转向再次碰运气。

## 13. 四种无面刻印

四种刻印只进入无面中枢奖励池：

| ID | 名称 | 操作 | 规则 |
| --- | --- | --- | --- |
| `engraving_low_murmur` | 低鸣 | `ECHO_LOWER_ADJACENT` | 所在规则台通过时，复制相邻骰中较低者的完整有效点数。 |
| `engraving_terminal_anchor` | 终点锚 | `ANCHOR_LAST_TABLE` | 激活后不能修改；处于本轮最后结算的有效规则台时固定加五。 |
| `engraving_two_way_bridge` | 双向桥 | `BRIDGE_BIDIRECTIONAL` | 把该骰一半有效点数向前后相邻有效规则台传递，分别向下取整。 |
| `engraving_sequence_prism` | 序列棱镜 | `PRISM_SEQUENCE` | 在连续数条件中可视为高一或低一的关系值，只改变条件判断，不改变计分点数。 |

规则：

- 刻印仍安装到具体骰子的具体面。
- 只有该面朝上且骰子已分配时生效。
- 每颗骰子最多一个刻印。
- 一次地区流程最多两个刻印。
- 候选从四种无面刻印中无放回选出三种。
- 同一固定种子与相同操作序列产生相同候选和顺序。

`PRISM_SEQUENCE` 若有多个可通过解释，只改变“是否通过”，
规则台计分仍使用骰子的真实有效点数，避免自动选择隐藏的高分解释。

## 14. 界面结构

稳定结构保存在 `.tscn`，脚本只负责数据绑定、状态刷新和信号。

### 14.1 主入口

地区试玩区域增加：

- `进入无面中枢`
- `重看无面中枢提示`

正常进入不重置提示状态。
重看入口只重置无面中枢自己的提示区段。

### 14.2 三回合日程条

首领战页面顶部增加固定日程条：

- 三个并列回合卡片。
- 每张显示方向、镜像规则和简短说明。
- 当前回合高亮。
- 已完成回合显示结果。
- 第三回合在选择前显示“待选择限制”。
- 选择后显示当前限制徽标。

日程条只读取会话状态，不自行切换遭遇。

### 14.3 限制选择面板

第二回合结束后打开模态面板：

- 两个候选左右并列。
- 分别标记“操作限制”和“分配限制”。
- 明确显示“仅影响第三回合”。
- 默认不预选。
- 选择前确认按钮禁用。
- 确认前可以来回比较。
- 确认后关闭面板并开始第三回合。
- 打开期间阻断下层所有输入。

限制文案和参数来自资源，不在场景脚本中重复维护一套常量。

### 14.4 限制状态与非法原因

第三回合持续显示限制徽标和摘要。

示例：

```text
独手裁决：第三回合最多使用 1 张真实手法牌。
三席到场：中间规则台尚未分配骰子。
```

分配限制同时显示“已覆盖 n/3 张规则台”。

### 14.5 新牌目标提示

- 选牌后只高亮合法目标。
- 不合法目标保持可识别的禁用状态。
- 点击或拖向非法目标时显示具体原因。
- 双骰牌分步骤显示“选择来源”和“选择目标”。
- 条件牌说明当前规则类型与所需类型。
- 情报牌在结算轨迹显示预计奖励。

不得为十六张牌逐张弹出教学窗口。

### 15.2 提示一：复合规则

- ID：`restriction`

> 两项限制都只影响第三回合，也都不会改变骰子结果。
> 比较当前牌组与剩余手牌后，选择你更有把握处理的一项。

### 15.5 队列与交互

- 提示使用现有引导队列，不与区域介绍、商店、限制、奖励或结算弹窗叠加。

- “知道了”、Enter、Esc 标记当前提示。

- 关闭后恢复此前应有的焦点和输入状态。

## 16. 原子性与错误处理

### 16.1 会话

- 缺少合法限制时保持 `AWAITING_RESTRICTION`。
- 非法限制 ID 不改变状态。
- 第三回合创建失败时恢复等待选择状态并显示原因。
- 已确认限制不能被撤销历史覆盖。

### 16.2 出牌与分配

- 任一目标非法时不消耗手牌或出牌额度。
- 双目标牌任一目标失效时整次操作失败。
- 分配限制失败时不提交部分骰子状态。
- 镜像副本、真实牌计数和限制校验使用同一份运行时数据。

### 16.3 奖励

- 情报奖励只在正式报告成功提交后兑现。
- 每个正式报告具有唯一兑现标识。
- 刻印安装验证当前刻印数、骰子 ID、骰面和重复占用。
- 任一奖励引用失效时不写入部分完成快照。

### 16.4 内容加载

内容校验器拒绝：

- 回合计划数量不是三。
- 限制数量或类别错误。
- 未知限制操作或负数参数。
- 空 ID、重复 ID 或空中文规则文本。
- 卡牌花色数量不符合最终目录。
- 双目标操作缺少目标。
- 条件修改牌与目标条件类型不匹配。
- 未知刻印操作。

开发构建在内容错误存在时阻止进入无面中枢，
并显示资源路径、字段和期望值。

## 17. 测试与验证

### 17.1 回合计划

- 三个回合按资源顺序切换遭遇。
- 第一、二回合结束后的状态不同。
- 第二回合后必须选择限制。
- 选择确认后不可更换。
- 无日程的旧遭遇保持原三回合行为。

### 17.2 限制

- 真实牌上限不统计镜像副本。
- 撤销真实牌后额度恢复。
- 重做重新经过限制校验。
- 三席限制指出左、中、右具体缺失位置。
- 被拒绝提交的状态快照完全不变。
- 两种限制下预演报告等于正式报告。

### 17.3 新牌

每张牌至少覆盖：

- 一个合法目标。
- 一个非法目标或非法状态。
- 预演事件。
- 正式提交。
- 撤销与重做。

额外覆盖：

- 双骰目标顺序。
- 条件宽限只影响指定台和当前轮。
- 情报奖励只兑现一次。
- 加严映射不会制造超出总骰数的非法容量。
- 第三回合操作限制与新牌目标校验组合。

### 17.4 新刻印

- 终点锚使用公开结算顺序判断最后有效台。
- 双向桥分别向前后有效台传递。

- 刻印总数为十二。
- 庄家总数为三。

- 两种限制改变最优操作，不存在恒定占优选项。
