# 远征复玩、挑战与横向进度设计规格

> 文档日期：2026-07-31
> 前置阶段：正式十八类规则池、差异化活动、混合庄家奖励、三类构筑身份
> 状态：设计已确认
> 文档边界：只暂存，不进入阶段代码提交

## 1. 目标

本阶段解决“完成一次三区远征后缺少下一局理由”的问题。新增内容必须改变出发配置、局内压力或复盘方式，不能用永久攻击力、分数倍率或资源倍率伪装成长。

## 2. 出发配置

### 2.1 三套起始牌组

出发前可以从三套固定十二张牌组中任选一套：

- 骰值控制：以调值、换值、复制、翻面和锁定为主。
- 规则台连锁：以映射、重复、桥接和反向结算为主。
- 情报经济：以返还校准、条件产出情报券和容错为主。

三套牌组从第一次启动起全部开放。每套牌组必须：

- 恰好十二张不同卡牌；
- 所有 ID 均来自正式卡牌目录；
- 至少有五张属于对应构筑身份；
- 在三区远征中均能形成合法商店池与庄家稀有牌候选。

### 2.2 种子

新远征默认生成正整数种子，也允许玩家手动输入。历史记录中的“同配置重开”必须同时恢复种子、起始牌组和挑战组合。

## 3. 六项公开挑战

首次完成完整三区远征后，六项挑战统一解锁。未首通时挑战仍显示，但不可启用，并明确写出解锁条件。

单局可启用零至两项；重复项、未知项和超过两项必须在领域层拒绝。

| ID | 名称 | 规则 |
|---|---|---|
| `high_pressure` | 高压合约 | 普通房与庄家累计目标提高 15%，向上取整 |
| `short_hand` | 精简手牌 | 非固定手牌活动每轮抽三张；公开固定手牌谜题不受影响 |
| `intel_squeeze` | 情报紧缩 | 每个普通房的基础成功情报奖励减少 1，最低为 0 |
| `market_surge` | 黑市涨价 | 换牌、刷新和购买情报各增加 1 情报券 |
| `no_undo` | 落子无悔 | 遭遇中禁止撤销；按钮禁用并显示原因 |
| `full_table_rule` | 全台公开 | 每轮提交时三张可见规则台都必须至少分配一颗骰子 |

“全台公开”是附加的全局公开限制，不增加第四张隐藏规则台，也不改变十八类正式规则池的单局抽取原则。

挑战名称与效果必须在出发页、区域状态和结算页持续可见。挑战应用必须由种子和配置决定，不允许中途随机隐藏变更。

## 4. 横向进度

长期进度仅包含：

- 是否完成过完整三区远征；
- 各构筑身份的完成次数；
- 各挑战的完成次数；
- 最近三十局远征记录。

不得写入永久目标降低、初始情报增加、卡牌数值提高或骰面加成。

## 5. 最近三十局

每条记录包含：

- 唯一局次 ID、结束时间、结果；
- 种子、起始牌组 ID、挑战 ID；
- 已完成区域、路线、庄家奖励；
- 最终牌组数量、剩余情报券和失败原因。

历史按结束时间倒序，最多保留三十条。相同局次 ID 重复写入必须幂等。损坏文件不得被静默覆盖，应沿用现有存档的显式错误与归档策略。

## 6. 存档兼容

进行中远征必须持久化起始牌组 ID、挑战 ID 和局次 ID。旧版合法存档迁移为：

- 起始牌组：骰值控制；
- 挑战：空；
- 局次 ID：根据旧种子和开始状态生成稳定兼容 ID。

迁移不能改变旧存档牌组、区域进度、随机状态或检查点。

## 7. 界面

新增独立“远征配置”页面，避免与正在进行的主菜单音乐/设置改动发生场景文件冲突。页面包含：

- 三套起始牌组单选卡；
- 六项挑战复选卡和 `0/2` 计数；
- 种子输入；
- 开始、返回；
- 最近三十局列表；
- 每条历史的“同配置重开”按钮。

主菜单“开始新远征”进入配置页；“继续远征”保持原流程。

## 8. 验收

- 三套起始牌组全部合法、立即可选且身份倾向可验证。
- 首通前挑战不可启用，完整通关后六项同时解锁。
- 22 种合法配置（无挑战、六个单项、十五个两两组合）均能启动并保持公开信息一致。
- 六项挑战的领域效果、保存恢复和 UI 文案一致。
- 完成与失败均只写入一条历史；超过三十条时移除最旧记录。
- 同配置重开恢复种子、牌组和挑战。
- 1280×720 与 1920×1080 无裁切；真实鼠标可完成配置、启动、查看历史和重开。
- 全量自动测试与三区既有端到端检查通过。
- 十局真人体验属于人工产品验收，不能以自动 PASS 替代。
