# Formal expedition feedback assets

These SVG files are original project assets created for the formal three-area expedition feedback system.

- `trace_gold_corridor.svg`: ledger route with abacus ticks.
- `trace_mirror_hall.svg`: mirrored axis with refracted shards.
- `trace_faceless_hub.svg`: three-node protocol circuit.
- `seal_*.svg`: rare factual highlight seals.

Source format: hand-authored SVG 1.1-compatible XML. Palette is restricted to the existing Dream Glass colors (`#07121C`, `#ADFFF5`, `#EBB8FF`, `#E7B84B`, `#79D8FF`, `#FF71B7`). No external artwork, font, or licensed source is embedded.
